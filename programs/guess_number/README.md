# Guess the Number

Guess a random integer from 1 to 1000; receive higher/lower hints, count attempts and optionally replay.

## Run

From the repository root:

```bash
python programs/guess_number/guess_number.py
```

Or choose the exercise from `python main.py`.

## From C to Python

Random values, loops, comparisons and error handling. Python uses indentation for blocks, `input()` for terminal input and `print()` for output. Compare these concepts with C's braces, `scanf()` and `printf()`.
