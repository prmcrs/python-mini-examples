# Basic Number Operations

Add two integers, compare two integers or multiply three integers.

## Run

From the repository root:

```bash
python programs/basic_number_op/basic_number_op.py
```

Or choose the exercise from `python main.py`.

## From C to Python

Functions, integer input, arithmetic and comparison operators. Python uses indentation for blocks, `input()` for terminal input and `print()` for output. Compare these concepts with C's braces, `scanf()` and `printf()`.
