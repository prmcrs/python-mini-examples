# Prime Numbers

Checks primality, lists primes up to an integer, and factorizes integers greater than or equal to 2.

## Run

From the repository root:

```bash
python programs/prime/prime.py
```

Or choose the exercise from `python main.py`.

## From C to Python

Functions, loops, modulus, integer square root and lists. Python uses indentation for blocks, `input()` for terminal input and `print()` for output. Compare these concepts with C's braces, `scanf()` and `printf()`.
