# Age Calculator

Reads a YYYY-MM-DD birth date and displays completed years and birth decade. Rejects future dates.

## Run

From the repository root:

```bash
python programs/age_calculator/age_calculator.py
```

Or choose the exercise from `python main.py`.

## From C to Python

Date parsing, comparisons and validation. Python uses indentation for blocks, `input()` for terminal input and `print()` for output. Compare these concepts with C's braces, `scanf()` and `printf()`.
