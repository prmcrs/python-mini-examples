# Hello World

Prints a greeting and a small ASCII drawing.

## Run

From the repository root:

```bash
python programs/hello_world/hello_world.py
```

Or choose the exercise from `python main.py`.

## From C to Python

Printing strings, escaping backslashes and raw string literals. Python uses indentation for blocks, `input()` for terminal input and `print()` for output. Compare these concepts with C's braces, `scanf()` and `printf()`.
